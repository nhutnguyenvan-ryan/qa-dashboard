# QA Dashboard — Shopee VN

Web dashboard hiển thị dữ liệu QA Monitoring.

## Deploy
- Backend: Node.js + Express (Render.com)
- Frontend: Vanilla HTML/JS/Chart.js (trong /public)

## Data files (đặt trong /data/)
- QA_Score_weekly.csv
- QA_score_monthly.csv
- Appeal.csv
- Leakage__Overkill_overall.csv

## Chạy local (nếu có Node.js)
```
npm install
npm start
```
